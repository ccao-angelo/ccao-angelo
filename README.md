### Vertical Campaign Agent

An AI-assisted portfolio prototype that turns a structured campaign brief into coordinated content drafts, with validation, human review, and tracking-link preparation.

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ccao-angelo/vertical-campaign-agent)
[![Live Demo](https://img.shields.io/badge/Open_Live_Demo-8A2BE2?style=for-the-badge&logo=render&logoColor=white)](https://vertical-campaign-agent.onrender.com)

<p align="center">
  <a href="https://vertical-campaign-agent.onrender.com">
    <img src="https://raw.githubusercontent.com/ccao-angelo/vertical-campaign-agent/main/docs/asset-review.png" alt="Vertical Campaign Agent interface for reviewing generated campaign assets" width="850" />
  </a>
</p>

**Built with:** React · TypeScript · Node.js · Express · Anthropic API · Zod · Vitest · Render

**What it does:**

- Produces email, LinkedIn, and digital-postcard drafts from one campaign brief.
- Creates alternate draft variants and grounds copy in approved campaign facts.
- Flags unsupported claims, changed CTAs, prohibited terms, and length violations.
- Requires human review before approval and supports regenerating individual assets.
- Generates campaign IDs, variant-level UTM links, and a proposed measurement plan.
- Exports campaign packages as JSON or Markdown, with API credentials kept on the server.

The project separates AI-generated copy from code-based validation and tracking logic. Shared Zod schemas validate data across the client and server.

**Scope:** This tool prepares drafts and tracking links. It does not publish campaigns, run live experiments, or collect conversion results.

[Architecture, setup, and limitations →](https://github.com/ccao-angelo/vertical-campaign-agent#readme)
