### Vertical Campaign Agent

> An AI-assisted B2B marketing workflow that transforms one structured campaign brief into coordinated, measurable content across multiple channels.

[![Repository](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/ccao-angelo/vertical-campaign-agent)
[![Live Demo](https://img.shields.io/badge/Open_Live_Demo-8A2BE2?style=for-the-badge&logo=render&logoColor=white)](https://vertical-campaign-agent.onrender.com)

<p align="center">
  <a href="https://vertical-campaign-agent.onrender.com">
    <img
      src="https://raw.githubusercontent.com/ccao-angelo/vertical-campaign-agent/main/docs/asset-review.png"
      alt="Vertical Campaign Agent asset review interface"
      width="850"
    />
  </a>
</p>

**Technology:** React · TypeScript · Node.js · Express · Anthropic API · Zod · Vitest · Render

**What it does:**

- Converts one campaign brief into email, LinkedIn, and digital-postcard assets
- Generates A/B variants for channel-specific campaign testing
- Grounds generated copy in numbered, approved campaign facts
- Flags unsupported claims, altered CTAs, prohibited terms, and length violations
- Requires human review before an asset can be approved
- Regenerates individual assets without replacing the rest of the campaign
- Generates deterministic campaign IDs and variant-level UTM links
- Creates a measurement plan with KPIs and conversion events
- Exports complete campaign packages as JSON or Markdown
- Keeps AI credentials protected on the server

The system separates generative copywriting from deterministic tracking, validation, and measurement logic. Shared Zod schemas validate data across the client and server, while campaign IDs, UTMs, KPIs, and quality checks are calculated in code for consistent and testable output.

> This is an independent portfolio project inspired by common B2B marketing workflows. It is not affiliated with or endorsed by Rundoo.
